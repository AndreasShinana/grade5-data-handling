1. What is Data?

Data is information collected about people, objects or events. For example, we can collect data about learners' favourite fruits.

2. Collecting and Recording Data

We can collect information by asking questions or conducting an interview. Tally marks help us count answers quickly.

Frequency tells us how many times an answer occurs.

3. Pictograms

A pictogram represents data using pictures or symbols. A key tells us what one symbol represents.

Key: 🍎 = 2 learners

Apple: 🍎 🍎 🍎 🍎 = 8 learners

Banana: 🍎 🍎 🍎 = 6 learners

Always check the key before counting the symbols.

4. Bar Graphs

A bar graph represents data using bars. A vertical bar graph normally has a title, labelled axes, categories, a suitable scale and bars of the correct height.

8Football

Example: Football is the most popular because its bar is the highest.

5. How to Interpret Data

  1. Read the title.
  2. Check the categories and labels.
  3. Check the scale or key.
  4. Read the values carefully.
  5. Use the information to answer questions and make a conclusion.
