GRADE 5 DATA HANDLING WEBSITE
================================

This folder contains a complete static website for the UNAM ICT in Teaching & Learning practical assignment.

TOPIC:
Grade 5 Mathematics — Data Handling: Pictograms and Bar Graphs

PAGES:
- index.html — Home, objectives and curriculum alignment
- learn.html — Learning content and teaching aids
- activity.html — Interactive group activity
- assessment.html — 5-question digital assessment + teacher memorandum
- support.html — Support for different learning needs
- citizenship.html — Digital citizenship
- reflection.html — Reflection, sources, AI disclosure and student details
- style.css — Website design

HOW TO TEST:
1. Open index.html in a web browser.
2. Use the navigation menu to move through all pages.
3. Test the assessment and its automatic checking.
4. Replace the student-detail blanks on reflection.html.

HOW TO PUBLISH:
Option A — GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a new repository.
3. Upload all files in this folder.
4. In repository Settings, open Pages.
5. Select the main branch/root folder and save.
6. GitHub will provide a public website URL.

Option B — Google Sites:
Use the page content as the basis for Google Sites and add the assessment as a Google Form. Google Sites does not directly import this HTML package as a complete site.

IMPORTANT:
- Add your full name and student number.
- Acknowledge any external images/videos you add.
- Do not publish learner personal information or photographs.
- Test the final public link before submitting it to the lecturer.
