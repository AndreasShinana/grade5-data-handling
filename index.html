Welcome!

Welcome to our Grade 5 Mathematics learning website. In this lesson, you will learn how to collect, organise, represent and interpret data using tables, pictograms and bar graphs.

Learning Objectives

By the end of the lesson, learners should be able to:

  1. Collect and record data using tally marks and a frequency table.
  2. Represent data using a pictogram or vertical bar graph with a suitable key or scale.
  3. Read and interpret information from pictograms and bar graphs.
  4. Answer questions based on information presented in tables and graphs.
  5. Make a simple conclusion or prediction from a data set.

Curriculum Alignment

Subject: Mathematics   Grade: 5   Topic: Data Handling
